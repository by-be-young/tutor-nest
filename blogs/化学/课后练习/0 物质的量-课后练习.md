1. 用 $N_A$ 表示阿伏加德罗常数的值，下列说法正确的是（ ）

    A. 常温下，$1\ \text{L}$ $\text{pH}=12$ 的 $\mathrm{Ba(OH)_2}$ 溶液中 $\mathrm{OH^-}$ 的数目为 $0.02N_A$

    B. 常温常压下，$\mathrm{SO_2}$ 与 $\mathrm{O_2}$ 的密度之比为 $2:1$

    C. 标准状况下，$11.2\ \text{L}$ $\mathrm{OF_2}$（气体）与水完全反应（生成 $\mathrm{O_2}$ 和 $\mathrm{HF}$）时转移的电子数目为 $2N_A$

    D. 标准状况下，$11.2\ \text{L}$ $\mathrm{Cl_2}$ 溶于水，所得溶液中 $\mathrm{Cl^-}$、$\mathrm{ClO^-}$、$\mathrm{HClO}$ 的粒子数目之和为 $N_A$

2. 将一定量锌与 $100\ \text{mL}$ $18\ \text{mol/L}$ 的浓硫酸充分反应，锌完全溶解时产生 $0.8\ \text{mol}$ 气体（不考虑气体在溶液中的溶解），将反应后的溶液稀释至 $400\ \text{mL}$，测得溶液中 $c(\mathrm{H^+}) = x\ \text{mol/L}$，则下列叙述错误的是（ ）

    A. 共消耗 $48.0\ \text{g}$ 锌

    B. 共转移 $1.6\ \text{mol}$ 电子

    C. 气体中 $\dfrac{n(\mathrm{SO_2})}{n(\mathrm{H_2})} = \dfrac{1 - 0.2x}{0.2(x - 1)}$

    D. 生成气体的体积约为 $17.92\ \text{L}$（标准状况）

    $\mathrm{Bi_2S_3 + 6Fe^{3+} = 2Bi^{3+} + 6Fe^{2+} + 3S}$

    $\mathrm{Bi^{3+} + H_2Y^{2-} = [BiY]^- + 2H^+}$

    已知：$\mathrm{BiCl_3}$ 易水解，$M(\mathrm{Bi}) = 209\ \text{g/mol}$。该样品中 $\mathrm{Bi^{3+}}$ 的质量分数为 \_\_\_\_\_\_\_\_\_\_ $\times 100\%$。（列出计算式，不用化简）
