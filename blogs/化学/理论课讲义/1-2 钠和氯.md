# 钠

**钠（Na）** 是第 11 号元素，位于元素周期表第三周期第ⅠA 族，最外层电子数为 1，是典型的活泼金属元素，也是短周期金属性最强的元素。钠元素常见的化合价为+1 价。

## 物理性质

金属钠在常温下为银白色、具有金属光泽的固体，质地柔软（可用刀切割），熔点较低，密度介于水和煤油之间（$\rho_{\text{煤油}} < \rho_{\text{Na}} < \rho_{\text{水}}$）。

## 化学性质

由于钠原子最外层只有 1 个电子，极易失去，因此金属钠（0 价）表现出极强的**还原性**，能与绝大多数氧化剂反应。

1. **与非金属单质反应**
   - 与氧气反应，常温与加热产物不同：
     - $4\mathrm{Na} + \mathrm{O_2} = 2\mathrm{Na_2O}$ （白色固体）
     - $2\mathrm{Na} + \mathrm{O_2} \xlongequal{\triangle} \mathrm{Na_2O_2}$ （淡黄色固体）

     *注：以上反应体现了温度的量变引起质变。*
   - 与卤素单质（$X_2$）反应：
     - $2\mathrm{Na} + X_2 \xlongequal{\triangle} 2\mathrm{Na}X$

     *注：燃烧是剧烈的发光发热的氧化反应，不一定有氧气参与。钠在加热时先熔化再燃烧，说明其熔点低于着火点。*

2. **与化合物反应**
   - 与水反应（滴有酚酞）：$2\mathrm{Na} + 2\mathrm{H_2O} = 2\mathrm{Na}^+ + 2\mathrm{OH}^- + \mathrm{H_2} \uparrow$，现象可概括为“**浮、熔、游、响、红**”。
   - 与酸反应：$2\mathrm{Na} + 2\mathrm{H}^+ = 2\mathrm{Na}^+ + \mathrm{H_2} \uparrow$
   - 与盐溶液反应（如 $\mathrm{CuSO_4}$ 溶液）：钠先与水反应生成 $\mathrm{NaOH}$，$\mathrm{NaOH}$ 再与 $\mathrm{CuSO_4}$ 反应生成 $\mathrm{Cu(OH)_2}$ 沉淀。总反应为 $2\mathrm{Na} + 2\mathrm{H_2O} + \mathrm{CuSO_4} = \mathrm{Cu(OH)_2} \downarrow + \mathrm{Na_2SO_4} + \mathrm{H_2} \uparrow$。
   - 与含-OH 的有机物反应：
     - $2\mathrm{Na} + 2\mathrm{C_2H_5OH} \rightarrow 2\mathrm{C_2H_5ONa} + \mathrm{H_2} \uparrow$（钠沉在乙醇底部，反应比与水缓慢）

## 用途与制备

- **用途**：
  - 钠钾合金（常温为液态）可用作核反应堆的**传热介质**。
  - 制作**高压钠灯**，利用其发出穿透性强的黄光。
  - **冶炼金属**，如利用其强还原性置换出钛、钾等：$\mathrm{4Na + TiCl_4 \xlongequal{高温} 4NaCl + Ti}$。
- **制备**：电解熔融氯化钠：$\mathrm{2NaCl(熔融) \xlongequal{电解} 2Na + Cl_2 \uparrow}$。

  *注：电解氯化钠水溶液得不到金属钠，因为水中的 $H^+$ 氧化性强于 $Na^+$，会优先放电。*
  
- **保存**：通常密封保存在煤油中，隔绝空气和水。钠着火时，应用干砂土或专用灭火剂灭火。

# 钠的氧化物

钠的常见氧化物有氧化钠（$\mathrm{Na_2O}$）和过氧化钠（$\mathrm{Na_2O_2}$）。二者的性质对比如下：

| 物质 | 氧化钠（$\mathrm{Na_2O}$） | 过氧化钠（$\mathrm{Na_2O_2}$） |
| :--- | :--- | :--- |
| **颜色、状态** | 白色固体 | 淡黄色固体 |
| **类别** | 碱性氧化物 | 过氧化物（不是碱性氧化物） |
| **氧的价态** | -2 价（稳价） | -1 价（非稳价） |
| **化学性质** | 具有碱性氧化物的通性 | 既有氧化性，又有还原性 |
| **与水反应** | $\mathrm{Na_2O + H_2O = 2NaOH}$ | $\mathrm{2Na_2O_2 + 2H_2O = 4NaOH + O_2 \uparrow}$ |
| **与 $\mathrm{CO_2}$ 反应** | $\mathrm{Na_2O + CO_2 = Na_2CO_3}$ | $\mathrm{2Na_2O_2 + 2CO_2 = 2Na_2CO_3 + O_2}$ |
| **主要用途** | 制取少量烧碱 | 强氧化剂、漂白剂、供氧剂 |

**注意**：$\mathrm{Na_2O_2}$ 中的氧为-1 价，是氧元素的中间价态。它遇到强还原剂时表现氧化性，被还原为-2 价；遇到强氧化剂时表现还原性，被氧化为 0 价。当与 $\mathrm{H_2O}$ 或 $\mathrm{CO_2}$ 等反应时，则发生**歧化反应**，此时每消耗 1 mol $\mathrm{Na_2O_2}$ 转移 1 mol电子。

# 氢化钠

氢化钠（$\mathrm{NaH}$）是一种离子化合物，电子式为 $\mathrm{Na^+ [:H]^-}$。其中氢元素为 **-1 价** ，具有极强的还原性。$\mathrm{NaH}$ 与水发生归中反应，生成氢气和氢氧化钠。

**化学方程式**：$\mathrm{NaH + H_2O = NaOH + H_2 \uparrow}$，该反应每生成 1 mol $\mathrm{H_2}$ 转移 1 mol 电子。

# 碳酸钠与碳酸氢钠

碳酸钠（$\mathrm{Na_2CO_3}$）和碳酸氢钠（$\mathrm{NaHCO_3}$）是重要的钠盐。

## 性质对比

| 名称 | 碳酸钠 | 碳酸氢钠 |
| :--- | :--- | :--- |
| **俗名** | 纯碱、苏打 | 小苏打 |
| **颜色、状态** | 白色粉末 | 细小的白色晶体 |
| **水溶性** | 易溶于水 | 可溶于水（溶解度小于碳酸钠） |
| **热稳定性** | 稳定，受热不分解 | 不稳定，受热易分解：$\mathrm{2NaHCO_3 \xlongequal{\triangle} Na_2CO_3 + H_2O + CO_2 \uparrow}$ |
| **与酸反应** | $\mathrm{CO_3^{2-} + H^+ = HCO_3^-}$ （少量酸） <br> $\mathrm{HCO_3^- + H^+ = CO_2 \uparrow + H_2O}$ （继续加酸） | $\mathrm{HCO_3^- + H^+ = CO_2 \uparrow + H_2O}$ （反应迅速） |
| **与碱反应** | 与 $\mathrm{NaOH}$ 不反应 | $\mathrm{NaHCO_3 + NaOH = Na_2CO_3 + H_2O}$ |
| **主要用途** | 制玻璃、造纸、制肥皂等 | 发酵粉、治疗胃酸过多、灭火器原料等 |

## 相互转化与鉴别

- **相互转化**：
  - $\mathrm{Na_2CO_3 \xrightarrow{+CO_2+H_2O} NaHCO_3}$
  - $\mathrm{NaHCO_3 \xrightarrow{\triangle} 或 +NaOH} \mathrm{Na_2CO_3}$

- **常用鉴别方法**：
  1. **热稳定性**：对固体加热，能产生使澄清石灰水变浑浊气体的是 $\mathrm{NaHCO_3}$。
  2. **与酸反应**：向溶液中逐滴加入稀盐酸，立即产生气泡的是 $\mathrm{NaHCO_3}$，开始无现象后来产生气泡的是 $\mathrm{Na_2CO_3}$。
  3. **测溶液 $\mathrm{pH}$**：等物质的量浓度的溶液，$\mathrm{Na_2CO_3}$ 溶液的碱性更强。

## 工业制备——侯氏制碱法

1. 向饱和食盐水中先通入足量 **$\mathrm{NH_3}$**，再通入足量 **$\mathrm{CO_2}$**，可析出碳酸氢钠晶体。
   $\mathrm{NaCl + H_2O + NH_3 + CO_2 = NH_4Cl + NaHCO_3 \downarrow}$
2. 过滤得到碳酸氢钠固体，加热分解即可得到纯碱。
   $\mathrm{2NaHCO_3 \xlongequal{\triangle} Na_2CO_3 + H_2O + CO_2 \uparrow}$

# 碱金属（Li、Na、K、Rb、Cs）

碱金属位于元素周期表第ⅠA 族，最外层均只有 1 个电子，性质呈现规律性变化。

## 碱金属的相似性与递变性

|  | 相似性 | 递变性（由 $\mathrm{Li \to Cs}$） |
| :--- | :--- | :--- |
| **原子结构** | 最外层均为 1 个电子 | 电子层数逐渐增多，原子半径逐渐增大 |
| **元素性质** | 金属性很强，最高正价均为+1 价 | 金属性逐渐增强 |
| **单质性质** | 都具有较强的还原性 | 还原性逐渐增强；与 $\mathrm{O_2}$ 反应产物越来越复杂；熔沸点逐渐降低（$\mathrm{Na}$、$\mathrm{K}$ 密度反常） |

## 碱金属的特性

- 碱金属一般都保存在煤油中，但**锂（Li）的密度小于煤油**，需固封在石蜡中保存。
- 试剂一般不能放回原瓶，但 $\mathrm{Na}$、$\mathrm{K}$ 等活泼金属用剩后**必须放回原试剂瓶**。
- $\mathrm{Li}$ 与 $\mathrm{O_2}$ 反应只生成 $\mathrm{Li_2O}$，不存在温度的量变引起质变。
- 由于对角线规则，$\mathrm{Li}$ 与 $\mathrm{Mg}$ 的部分性质相似，例如碳酸锂（$\mathrm{Li_2CO_3}$）微溶于水。

# 氯元素

**氯（Cl）** 是第 17 号元素，位于元素周期表第三周期第ⅦA 族，最外层电子数为 7，是典型的活泼非金属元素，在自然界中以化合态形式存在。氯元素常见的化合价有 -1、0、+1、+3、+4、+5、+7 等，其中 -1 价为氯元素的稳价（稳定价态）。

# 氯气

## 氯气的物理性质

常温下，$\mathrm{Cl_2}$ 是一种黄绿色有刺激性气味的有毒气体，可溶于水（在常温常压下，1 体积的水可溶解约 2 体积的 $\mathrm{Cl_2}$），密度大于空气，易液化，液氯储存在钢瓶中。

## 化学性质

$\mathrm{Cl_2}$ 中 $\mathrm{Cl}$ 元素的化合价为 0，是氯元素的中间价，既有氧化性又有还原性。由于稳价是 -1 价，所以 $\mathrm{Cl_2}$ 主要体现氧化性。根据由强制弱规律，能被 $\mathrm{Cl_2}$ 氧化的还原剂有 $\mathrm{Na}$、$\mathrm{Al}$、$\mathrm{Fe}$、$\mathrm{Cu}$ 等金属单质，以及 $\mathrm{S^{2-}}$、$\mathrm{I^-}$、$\mathrm{Br^-}$ 等。

### 与金属单质反应

① 铁在 $\mathrm{Cl_2}$ 中剧烈燃烧，释放大量的热，生成棕褐色的烟：
$$\mathrm{2Fe + 3Cl_2 \xlongequal{\triangle} 2FeCl_3}$$

② 铜在 $\mathrm{Cl_2}$ 中剧烈燃烧，释放大量的热，生成棕黄色的烟：
$$\mathrm{Cu + Cl_2 \xlongequal{\triangle} CuCl_2}$$

**注：**
i. $\mathrm{Cl_2}$ 的氧化性强，与变价金属反应不存在量变引起质变，产物是高价金属氯化物。
ii. 虽然 $\mathrm{Cl_2}$ 在加热时可以与铁单质反应，但常温下不与铁单质反应，液氯可以用钢瓶储运。

### 与 $\mathrm{H_2}$ 反应

$\mathrm{H_2}$ 在 $\mathrm{Cl_2}$ 中安静燃烧，发出苍白色火焰，瓶口有白雾：
$$\mathrm{H_2 + Cl_2 \xlongequal{点燃} 2HCl}$$

### 与其他化合物反应

 ① 与 $\mathrm{SO_2}$ 反应：
$$\mathrm{SO_2 + Cl_2 + 2H_2O = SO_4^{2-} + 2Cl^- + 4H^+}$$

② 与 $\mathrm{KI}$ 反应：
$$\mathrm{2I^- + Cl_2 = I_2 + 2Cl^-}$$

③ 与 $\mathrm{FeCl_2}$ 反应：
$$\mathrm{2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-}$$

④ 与 $\mathrm{KBr}$ 反应：
$$\mathrm{2Br^- + Cl_2 = Br_2 + 2Cl^-}$$

### 氯气参与的歧化反应

氯气性质活泼，除了与一些还原性物质反应外，还可以与水、碱等发生歧化反应。

① $\mathrm{Cl_2}$ 通入水中制氯水：
$$\mathrm{Cl_2 + H_2O \rightleftharpoons HClO + Cl^- + H^+}$$
（可逆反应，水中的部分 $\mathrm{Cl_2}$ 与水反应，因此水中还有 $\mathrm{Cl_2}$ 存在，且新制氯水的主要溶质为 $\mathrm{Cl_2}$）

② $\mathrm{Cl_2}$ 通入 $\mathrm{NaOH}$ 溶液制漂白液或消毒液：
$$\mathrm{Cl_2 + 2OH^- = Cl^- + ClO^- + H_2O}$$

③ $\mathrm{Cl_2}$ 通入冷的石灰乳制漂白粉或漂粉精：
$$\mathrm{Cl_2 + Ca(OH)_2 = Cl^- + ClO^- + Ca^{2+} + H_2O}$$
石灰乳为悬浊液，$\mathrm{Ca(OH)_2}$ 不拆成离子

**注：** 自来水的净化主要包括杀菌消毒和聚沉。强氧化剂如 $\mathrm{ClO_2}$、$\mathrm{Cl_2}$、$\mathrm{O_3}$、$\mathrm{K_2FeO_4}$ 可用于杀菌消毒，而明矾主要利用其水解产生的胶体吸附杂质而聚沉。

### 氯水的成分及其性质

| 对象 | 新制氯水 | 久置氯水 | 液氯 |
| :--- | :--- | :--- | :--- |
| **成分** | $\mathrm{H_2O}$、$\mathrm{Cl_2}$、$\mathrm{HClO}$、$\mathrm{H^+}$、$\mathrm{Cl^-}$、$\mathrm{ClO^-}$、$\mathrm{OH^-}$（3 分 4 离） | $\mathrm{H_2O}$、$\mathrm{H^+}$、$\mathrm{Cl^-}$、$\mathrm{OH^-}$（1 分 3 离） | $\mathrm{Cl_2}$ |
| **性质** | 氧化性、酸性、漂白性 | 酸性 | 氧化性 |

**注：** 氯水中的主要溶质是 $\mathrm{Cl_2}$，所以当氯水参与化学反应作氧化剂时，优先考虑 $\mathrm{Cl_2}$ 参与反应，但氯水的漂白性通过 $\mathrm{HClO}$ 体现。

### 与有机物的反应

在一定条件下，$\mathrm{Cl_2}$ 还可以与很多有机物发生反应，对应化学方程式详见第 12 章。

## $\mathrm{Cl_2}$ 的用途

（1）可以对自来水杀菌消毒；
（2）冶炼金属：
$$\mathrm{TiO_2 + 2C + 2Cl_2 \xlongequal{高温} TiCl_4 + 2CO}$$
（氯化法冶炼钛的第一步）；
（3）制备盐酸；
（4）有机合成：
$$\mathrm{CH_4 + 4Cl_2 \xrightarrow{光} CCl_4 + 4HCl}$$

## 工业上电解饱和食盐水制取 $\mathrm{Cl_2}$

$$\mathrm{2NaCl + 2H_2O \xlongequal{电解} 2NaOH + H_2 \uparrow + Cl_2 \uparrow}$$
（阳极产生 $\mathrm{Cl_2}$、阴极产生 $\mathrm{H_2}$）

## $\mathrm{Cl_2}$ 的实验室制取

### 原理

$$\mathrm{HCl \xrightarrow{MnO_2、KMnO_4、KClO_3、K_2Cr_2O_7} Cl_2}$$

① 舍勒实验室制备 $\mathrm{Cl_2}$：
$$\mathrm{MnO_2 + 4H^+ + 2Cl^- \xlongequal{\triangle} Mn^{2+} + Cl_2 \uparrow + 2H_2O}$$

② 高锰酸钾法：
$$\mathrm{2MnO_4^- + 10Cl^- + 16H^+ = 2Mn^{2+} + 5Cl_2 \uparrow + 8H_2O}$$

③ 重铬酸钾法：
$$\mathrm{Cr_2O_7^{2-} + 14H^+ + 6Cl^- = 2Cr^{3+} + 3Cl_2 \uparrow + 7H_2O}$$

④ 氯酸钾法：
$$\mathrm{ClO_3^- + 6H^+ + 5Cl^- = 3Cl_2 \uparrow + 3H_2O}$$

⑤ 漂白粉或漂白液法：
$$\mathrm{ClO^- + Cl^- + 2H^+ = Cl_2 \uparrow + H_2O}$$

**注：**
i. 由于 $\mathrm{MnO_2}$ 的氧化性相对小一些，所以与其反应的盐酸浓度要求高一些，且需要加热。
ii. 84 消毒液含 $\mathrm{NaClO}$，洁厕灵含 $\mathrm{HCl}$，两者不能混合使用，以免生成有毒的 $\mathrm{Cl_2}$。

### 除杂方法

由于各方法均用盐酸做还原剂，盐酸有挥发性，所以 $\mathrm{Cl_2}$ 中始终混有 $\mathrm{HCl}$，需要用饱和食盐水除去 $\mathrm{HCl}$（利用 $\mathrm{Cl^-}$ 的同离子效应能抑制 $\mathrm{Cl_2}$ 与水的反应，进而降低 $\mathrm{Cl_2}$ 的溶解量）。

### 干燥方法

$\mathrm{Cl_2}$ 会与碱石灰反应，不能用碱石灰干燥，可使用浓硫酸、$\mathrm{P_2O_5}$、无水 $\mathrm{CaCl_2}$ 等干燥。

### 收集方法

$\mathrm{Cl_2}$ 有毒，且密度大于空气，所以收集 $\mathrm{Cl_2}$ 的方法主要是排液法（排饱和食盐水）和密闭体系的向上排空气法。

### 尾气处理方法

$\mathrm{Cl_2}$ 会与碱石灰反应，且又具有较强氧化性，所以用于 $\mathrm{Cl_2}$ 尾气处理的试剂可以是碱性物质，如 $\mathrm{NaOH}$ 溶液，也可以是某些还原性物质，如足量 $\mathrm{Na_2SO_3}$ 溶液、$\mathrm{FeCl_2}$ 溶液（可同时加入 $\mathrm{Fe}$ 粉）等。

**注：** 由于 $\mathrm{Ca(OH)_2}$ 的溶解度小，所以一般不用澄清石灰水吸收 $\mathrm{Cl_2}$，但可以用石灰乳。

① 若将氧化剂换成 $\mathrm{KMnO_4}$、$\mathrm{K_2Cr_2O_7}$、$\mathrm{KClO_3}$、$\mathrm{KClO}$ 等，则不需要加热。
② 在探究型实验中，杂质 $\mathrm{HCl}$、$\mathrm{H_2O}$ 若对实验无干扰，则无需除去。

# 氯的氧化物

| 氧化物 | $\mathrm{Cl_2O}$ | $\mathrm{ClO}$ | $\mathrm{ClO_2}$ | $\mathrm{Cl_2O_5}$ | $\mathrm{Cl_2O_7}$ |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Cl 化合价** | +1 | +2 | +4 | +5 | +7 |
| **是否为酸性氧化物** | 是 | 否 | 否 | 是 | 是 |
| **对应化合价的钠盐** | $\mathrm{NaClO}$ | — | — | $\mathrm{NaClO_3}$ | $\mathrm{NaClO_4}$ |

**注：** 因为 $\mathrm{Cl}$ 元素的稳价为 -1 价，所以上述氧化物均有强氧化性；在高中书写陌生方程式时，若题目没有特别交代，一般默认还原产物为 $\mathrm{Cl^-}$。

# 含氯的酸

## 常见含氯酸的名称

| 名称 | 盐酸（氢氯酸） | 次氯酸 | 亚氯酸 | 氯酸 | 高氯酸 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **化学式** | $\mathrm{HCl}$ | $\mathrm{HClO}$ | $\mathrm{HClO_2}$ | $\mathrm{HClO_3}$ | $\mathrm{HClO_4}$ |
| **酸性** | 强酸 | 弱酸 | 中强酸 | 强酸 | 强酸（高中最强） |

**注：**
（1）四种含氧酸酸性强弱顺序：$\mathrm{HClO_4 > HClO_3 > HClO_2 > HClO}$
（2）氧化性强弱顺序：$\mathrm{HClO > HClO_3}$（由此可见，同种元素化合价越高，氧化性不一定越强）。

## 盐酸

（1）$\mathrm{HCl}$ 气体极易溶于水，在常温常压下，1 体积的水可溶解约 500 体积的 $\mathrm{HCl}$。吸收 $\mathrm{HCl}$ 气体时，要注意防倒吸。$\mathrm{HCl}$ 溶于水形成盐酸，盐酸易挥发。

（2）盐酸为一元强酸，具有强酸的通性：① 与指示剂显色；② 与碱反应生成盐和水；③ 与碱性氧化物反应生成盐和水；④ 与盐反应生成新盐和新酸；⑤ 与活泼金属反应生成 $\mathrm{H_2}$。

（3）浓盐酸可与一些较强的氧化剂（$\mathrm{KMnO_4}$、$\mathrm{K_2Cr_2O_7}$、$\mathrm{KClO_3}$、$\mathrm{KClO}$）反应，$\mathrm{HCl}$ 体现还原性和酸性。

例：
$$\mathrm{MnO_2 + 4HCl(浓) \xlongequal{\triangle} MnCl_2 + Cl_2 \uparrow + 2H_2O}$$

当盐酸稀释到一定浓度时，该反应无法进行。$\mathrm{HCl}$ 在该反应中体现了酸性（生成 $\mathrm{MnCl_2}$）和还原性（生成 $\mathrm{Cl_2}$）

（4）配位反应（王水可以溶解铂、金）

① 化学方程式：
$$\mathrm{Au + HNO_3 + 4HCl = HAuCl_4 + NO \uparrow + 2H_2O}$$

② 离子方程式：
$$\mathrm{Au + NO_3^- + 4Cl^- + 4H^+ = AuCl_4^- + NO \uparrow + 2H_2O}$$

## 次氯酸（$\mathrm{HClO}$）

（1）酸性：$\mathrm{HClO}$ 的 $K_a$ 介于碳酸的 $K_{a1}$ 与 $K_{a2}$ 之间，因此 $\mathrm{HClO}$ 可与 $\mathrm{Na_2CO_3}$ 反应生成 $\mathrm{NaClO}$ 与 $\mathrm{NaHCO_3}$，但 $\mathrm{HClO}$ 不与 $\mathrm{NaHCO_3}$ 反应。

（2）$\mathrm{HClO}$ 不稳定，光照（或受热）容易分解产生氧气：
$$\mathrm{2HClO \xlongequal{光照} 2HCl + O_2 \uparrow}$$

（3）强氧化性和漂白性：将有机色素氧化成无色物质，该氧化还原反应不可逆。

**注：**
① 次氯酸的酸性较弱，但其氧化性却极强。酸性强弱与电离出 $\mathrm{H^+}$ 的能力有关，而氧化性强弱与得电子能力相关，二者并无矛盾。
② $\mathrm{Cl_2}$ 不能使干燥有色布条褪色，说明 $\mathrm{Cl_2}$ 无漂白性；但湿润有色布条接触 $\mathrm{Cl_2}$ 却褪色了，原因是 $\mathrm{Cl_2}$ 与水反应生成的 $\mathrm{HClO}$ 具有强氧化性，能将有机色素氧化成无色物质。

# 含氯的盐

## 盐酸盐

（1）溶解度：绝大多数盐酸盐易溶，但是 $\mathrm{AgCl}$ 既难溶于水，又难溶于硝酸。

**注：** $\mathrm{AgCl}$ 因与某些阴离子或分子发生配位反应可以溶于浓盐酸、$\mathrm{Na_2S_2O_3}$ 溶液、$\mathrm{NaCN}$ 溶液、氨水，分别生成 $[\mathrm{AgCl_2}]^-$、$[\mathrm{Ag(S_2O_3)_2}]^{3-}$、$[\mathrm{Ag(CN)_2}]^-$、$[\mathrm{Ag(NH_3)_2}]^+$；$\mathrm{CuCl}$ 微溶于水。

（2）检验 $\mathrm{Cl^-}$ 的方法：向待测液中加入硝酸酸化的硝酸银，若有白色沉淀生成，则有 $\mathrm{Cl^-}$。

## 次氯酸盐

### 漂白粉、漂白液的组成、制备及变质原理

| 对象 | 漂白液 | 漂白粉 |
| :--- | :--- | :--- |
| **制备原理** | $\mathrm{Cl_2 + 2NaOH = NaClO + NaCl + H_2O}$ | $\mathrm{2Cl_2 + 2Ca(OH)_2 = Ca(ClO)_2 + CaCl_2 + 2H_2O}$ |
| **主要成分** | $\mathrm{NaClO}$、$\mathrm{NaCl}$ | $\mathrm{Ca(ClO)_2}$、$\mathrm{CaCl_2}$ |
| **有效成分** | $\mathrm{NaClO}$ | $\mathrm{Ca(ClO)_2}$ |
| **失效原理** | ① $\mathrm{NaClO + CO_2 + H_2O = HClO + NaHCO_3}$ <br> ② $\mathrm{2HClO \xlongequal{光照} 2HCl + O_2 \uparrow}$ | ① $\mathrm{Ca(ClO)_2 + CO_2 + H_2O = 2HClO + CaCO_3 \downarrow}$ <br> ② $\mathrm{2HClO \xlongequal{光照} 2HCl + O_2 \uparrow}$ |

**注：** $\mathrm{NaClO}$ 溶液与 $\mathrm{CO_2}$ 反应无量变引起质变，$\mathrm{CO_2}$ 的产物为 $\mathrm{NaHCO_3}$。$\mathrm{Ca(ClO)_2}$ 溶液与 $\mathrm{CO_2}$ 反应存在量变引起质变，当 $\mathrm{CO_2}$ 少时，产物为 $\mathrm{CaCO_3}$；当 $\mathrm{CO_2}$ 多时，产物为 $\mathrm{Ca(HCO_3)_2}$。

### 次氯酸盐的强氧化性

$\mathrm{ClO^-}$ 有很强的氧化性，能与很多还原剂反应，如 $\mathrm{S^{2-}}$、$\mathrm{SO_2}$、$\mathrm{I^-}$、$\mathrm{Fe^{2+}}$、$\mathrm{Br^-}$、$\mathrm{Cl^-}$ 等。

① 向漂白液中通入足量 $\mathrm{SO_2}$：
$$\mathrm{ClO^- + SO_2 + H_2O = Cl^- + SO_4^{2-} + 2H^+}$$

② 向漂白液中通入少量 $\mathrm{SO_2}$：
$$\mathrm{3ClO^- + SO_2 + H_2O = Cl^- + SO_4^{2-} + 2HClO}$$
（既要考虑氧化还原，又要考虑较强酸制较弱酸）

## 氯酸钾（$\mathrm{KClO_3}$）

氯酸钾有较强氧化性，可以制备氧化性气体，如 $\mathrm{O_2}$、$\mathrm{Cl_2}$ 等。

（1）利用 $\mathrm{KClO_3}$ 分解制 $\mathrm{O_2}$：
$$\mathrm{2KClO_3 \xlongequal[MnO_2]{\triangle} 2KCl + 3O_2 \uparrow}$$

（2）利用 $\mathrm{KClO_3}$ 制 $\mathrm{Cl_2}$：
$$\mathrm{KClO_3 + 6HCl(浓) = KCl + 3Cl_2 \uparrow + 3H_2O}$$
（归中反应，每消耗 1 mol $\mathrm{KClO_3}$，转移电子数为 $5N_A$）
