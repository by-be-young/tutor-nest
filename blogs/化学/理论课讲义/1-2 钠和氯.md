# 钠

**钠（Na）** 是第 11 号元素，位于元素周期表第三周期第ⅠA 族，最外层电子数为 1，是典型的活泼金属元素，也是短周期金属性最强的元素。钠元素常见的化合价为+1 价。

## 物理性质

金属钠在常温下为银白色、具有金属光泽的固体，质地柔软（可用刀切割），熔点较低，密度介于水和煤油之间（$\rho_{\text{煤油}} < \rho_{\text{Na}} < \rho_{\text{水}}$）。

## 化学性质

由于钠原子最外层只有 1 个电子，极易失去，因此金属钠（0 价）表现出极强的**还原性**，能与绝大多数氧化剂反应。

1. **与非金属单质反应**
   - 与氧气反应，常温与加热产物不同：
     - $4\mathrm{Na} + \mathrm{O_2} = 2\mathrm{Na_2O}$ （白色固体）
     - $2\mathrm{Na} + \mathrm{O_2} \xlongequal{\triangle} \mathrm{Na_2O_2}$ （淡黄色固体）

     *注：以上反应体现了温度的量变引起质变。*
   - 与卤素单质（$X_2$）反应：
     - $2\mathrm{Na} + X_2 \xlongequal{\triangle} 2\mathrm{Na}X$

     *注：燃烧是剧烈的发光发热的氧化反应，不一定有氧气参与。钠在加热时先熔化再燃烧，说明其熔点低于着火点。*

2. **与化合物反应**
   - 与水反应（滴有酚酞）：$2\mathrm{Na} + 2\mathrm{H_2O} = 2\mathrm{Na}^+ + 2\mathrm{OH}^- + \mathrm{H_2} \uparrow$，现象可概括为“**浮、熔、游、响、红**”。
   - 与酸反应：$2\mathrm{Na} + 2\mathrm{H}^+ = 2\mathrm{Na}^+ + \mathrm{H_2} \uparrow$
   - 与盐溶液反应（如 $\mathrm{CuSO_4}$ 溶液）：钠先与水反应生成 $\mathrm{NaOH}$，$\mathrm{NaOH}$ 再与 $\mathrm{CuSO_4}$ 反应生成 $\mathrm{Cu(OH)_2}$ 沉淀。总反应为 $2\mathrm{Na} + 2\mathrm{H_2O} + \mathrm{CuSO_4} = \mathrm{Cu(OH)_2} \downarrow + \mathrm{Na_2SO_4} + \mathrm{H_2} \uparrow$。
   - 与含-OH 的有机物反应：
     - $2\mathrm{Na} + 2\mathrm{C_2H_5OH} \rightarrow 2\mathrm{C_2H_5ONa} + \mathrm{H_2} \uparrow$（钠沉在乙醇底部，反应比与水缓慢）

## 用途与制备

- **用途**：
  - 钠钾合金（常温为液态）可用作核反应堆的**传热介质**。
  - 制作**高压钠灯**，利用其发出穿透性强的黄光。
  - **冶炼金属**，如利用其强还原性置换出钛、钾等：$\mathrm{4Na + TiCl_4 \xlongequal{高温} 4NaCl + Ti}$。
- **制备**：电解熔融氯化钠：$\mathrm{2NaCl(熔融) \xlongequal{电解} 2Na + Cl_2 \uparrow}$。

  *注：电解氯化钠水溶液得不到金属钠，因为水中的 $H^+$ 氧化性强于 $Na^+$，会优先放电。*
  
- **保存**：通常密封保存在煤油中，隔绝空气和水。钠着火时，应用干砂土或专用灭火剂灭火。

# 钠的氧化物

钠的常见氧化物有氧化钠（$\mathrm{Na_2O}$）和过氧化钠（$\mathrm{Na_2O_2}$）。二者的性质对比如下：

| 物质 | 氧化钠（$\mathrm{Na_2O}$） | 过氧化钠（$\mathrm{Na_2O_2}$） |
| :--- | :--- | :--- |
| **颜色、状态** | 白色固体 | 淡黄色固体 |
| **类别** | 碱性氧化物 | 过氧化物（不是碱性氧化物） |
| **氧的价态** | -2 价（稳价） | -1 价（非稳价） |
| **化学性质** | 具有碱性氧化物的通性 | 既有氧化性，又有还原性 |
| **与水反应** | $\mathrm{Na_2O + H_2O = 2NaOH}$ | $\mathrm{2Na_2O_2 + 2H_2O = 4NaOH + O_2 \uparrow}$ |
| **与 $\mathrm{CO_2}$ 反应** | $\mathrm{Na_2O + CO_2 = Na_2CO_3}$ | $\mathrm{2Na_2O_2 + 2CO_2 = 2Na_2CO_3 + O_2}$ |
| **主要用途** | 制取少量烧碱 | 强氧化剂、漂白剂、供氧剂 |

**注意**：$\mathrm{Na_2O_2}$ 中的氧为-1 价，是氧元素的中间价态。它遇到强还原剂时表现氧化性，被还原为-2 价；遇到强氧化剂时表现还原性，被氧化为 0 价。当与 $\mathrm{H_2O}$ 或 $\mathrm{CO_2}$ 等反应时，则发生**歧化反应**，此时每消耗 1 mol $\mathrm{Na_2O_2}$ 转移 1 mol电子。

# 氢化钠

氢化钠（$\mathrm{NaH}$）是一种离子化合物，电子式为 $\mathrm{Na^+ [:H]^-}$。其中氢元素为 **-1 价** ，具有极强的还原性。$\mathrm{NaH}$ 与水发生归中反应，生成氢气和氢氧化钠。

**化学方程式**：$\mathrm{NaH + H_2O = NaOH + H_2 \uparrow}$，该反应每生成 1 mol $\mathrm{H_2}$ 转移 1 mol 电子。

# 碳酸钠与碳酸氢钠

碳酸钠（$\mathrm{Na_2CO_3}$）和碳酸氢钠（$\mathrm{NaHCO_3}$）是重要的钠盐。

## 性质对比

| 名称 | 碳酸钠 | 碳酸氢钠 |
| :--- | :--- | :--- |
| **俗名** | 纯碱、苏打 | 小苏打 |
| **颜色、状态** | 白色粉末 | 细小的白色晶体 |
| **水溶性** | 易溶于水 | 可溶于水（溶解度小于碳酸钠） |
| **热稳定性** | 稳定，受热不分解 | 不稳定，受热易分解：$\mathrm{2NaHCO_3 \xlongequal{\triangle} Na_2CO_3 + H_2O + CO_2 \uparrow}$ |
| **与酸反应** | $\mathrm{CO_3^{2-} + H^+ = HCO_3^-}$ （少量酸） <br> $\mathrm{HCO_3^- + H^+ = CO_2 \uparrow + H_2O}$ （继续加酸） | $\mathrm{HCO_3^- + H^+ = CO_2 \uparrow + H_2O}$ （反应迅速） |
| **与碱反应** | 与 $\mathrm{NaOH}$ 不反应 | $\mathrm{NaHCO_3 + NaOH = Na_2CO_3 + H_2O}$ |
| **主要用途** | 制玻璃、造纸、制肥皂等 | 发酵粉、治疗胃酸过多、灭火器原料等 |

## 相互转化与鉴别

- **相互转化**：
  - $\mathrm{Na_2CO_3 \xrightarrow{+CO_2+H_2O} NaHCO_3}$
  - $\mathrm{NaHCO_3 \xrightarrow{\triangle} 或 +NaOH} \mathrm{Na_2CO_3}$

- **常用鉴别方法**：
  1. **热稳定性**：对固体加热，能产生使澄清石灰水变浑浊气体的是 $\mathrm{NaHCO_3}$。
  2. **与酸反应**：向溶液中逐滴加入稀盐酸，立即产生气泡的是 $\mathrm{NaHCO_3}$，开始无现象后来产生气泡的是 $\mathrm{Na_2CO_3}$。
  3. **测溶液 $\mathrm{pH}$**：等物质的量浓度的溶液，$\mathrm{Na_2CO_3}$ 溶液的碱性更强。

## 工业制备——侯氏制碱法

1. 向饱和食盐水中先通入足量 **$\mathrm{NH_3}$**，再通入足量 **$\mathrm{CO_2}$**，可析出碳酸氢钠晶体。
   $\mathrm{NaCl + H_2O + NH_3 + CO_2 = NH_4Cl + NaHCO_3 \downarrow}$
2. 过滤得到碳酸氢钠固体，加热分解即可得到纯碱。
   $\mathrm{2NaHCO_3 \xlongequal{\triangle} Na_2CO_3 + H_2O + CO_2 \uparrow}$

# 碱金属（Li、Na、K、Rb、Cs）

碱金属位于元素周期表第ⅠA 族，最外层均只有 1 个电子，性质呈现规律性变化。

## 碱金属的相似性与递变性

|  | 相似性 | 递变性（由 $\mathrm{Li \to Cs}$） |
| :--- | :--- | :--- |
| **原子结构** | 最外层均为 1 个电子 | 电子层数逐渐增多，原子半径逐渐增大 |
| **元素性质** | 金属性很强，最高正价均为+1 价 | 金属性逐渐增强 |
| **单质性质** | 都具有较强的还原性 | 还原性逐渐增强；与 $\mathrm{O_2}$ 反应产物越来越复杂；熔沸点逐渐降低（$\mathrm{Na}$、$\mathrm{K}$ 密度反常） |

## 碱金属的特性

- 碱金属一般都保存在煤油中，但**锂（Li）的密度小于煤油**，需固封在石蜡中保存。
- 试剂一般不能放回原瓶，但 $\mathrm{Na}$、$\mathrm{K}$ 等活泼金属用剩后**必须放回原试剂瓶**。
- $\mathrm{Li}$ 与 $\mathrm{O_2}$ 反应只生成 $\mathrm{Li_2O}$，不存在温度的量变引起质变。
- 由于对角线规则，$\mathrm{Li}$ 与 $\mathrm{Mg}$ 的部分性质相似，例如碳酸锂（$\mathrm{Li_2CO_3}$）微溶于水。
