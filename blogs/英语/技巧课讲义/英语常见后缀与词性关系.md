# 名词后缀

- **-tion / -sion** (动作/状态)： **educate** → education； **decide** → decision
    
- **-ment** (行为/结果)： **develop** → development； **argue** → argument
    
- **-ness** (性质/状态)： **happy** → happiness； **dark** → darkness
    
- **-ity / -ty** (属性)： **active** → activity； **safe** → safety
    
- **-ance / -ence** (性质/动作)： **important** → importance； **depend** → dependence
    
- **-er / -or** (施动者)： **teach** → teacher； **act** → actor
    
- **-ism** (主义/学说)： **real** → realism； **social** → socialism
    
- **-hood** (身份/时期)： **child** → childhood； **neighbor** → neighborhood
    
- **-ship** (关系/技能)： **friend** → friendship； **leader** → leadership
    

# 动词后缀 

- **-ize / -ise** (使…化)： **modern** → modernize； **real** → realize
    
- **-ify** (使成为)： **simple** → simplify； **beauty** → beautify
    
- **-en** (使变得)： **wide** → widen； **deep** → deepen
    
- **-ate** (使具有)： **active** → activate； **origin** → originate
    

# 形容词后缀 

- **-able / -ible** (可…的)： **read** → readable； **access** → accessible
    
- **-ful** (充满…的)： **hope** → hopeful； **care** → careful
    
- **-less** (缺乏…的)： **hope** → hopeless； **care** → careless
    
- **-ous** (具有…性质的)： **danger** → dangerous； **fame** → famous
    
- **-al / -ial** (与…有关的)： **nature** → natural； **industry** → industrial
    
- **-ic / -ical** (属于…的)： **economy** → economic； **history** → historical
    
- **-ive** (有…倾向的)： **act** → active； **create** → creative
    
- **-y** (充满/带有)： **rain** → rainy； **sun** → sunny
    
- **-ish** (略微/归属)： **child** → childish； **fool** → foolish
    

# 副词后缀 

- **-ly** (方式/程度)： **quick** → quickly； **happy** → happily
    
- **-ward (s)** (方向)： **back** → backward (s)； **home** → homeward
